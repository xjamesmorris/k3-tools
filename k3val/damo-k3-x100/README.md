# DAMO privileged suite: K3 X100 port

This directory adapts XUANTIE-RV's
[damo-rv-priv-ats](https://github.com/XUANTIE-RV/damo-rv-priv-ats), at
`824dbb02ce20a6ceabb3ea0665496f0b19bcce19`, to X100 hart 0 of the SpacemiT
K3 in M-mode. `k3val build-x100` applies it to a dedicated checkout of that
revision; the [k3val README](../README.md#the-k3-x100-port) describes what
each part does.

| Path | Origin | License |
| --- | --- | --- |
| `config/k3-x100/platform_config.h` | Changed from upstream `config/qemu-rv64-max/platform_config.h` | Apache-2.0; upstream notice kept |
| `config/k3-x100/rvmodel_macros.h` | Changed from upstream `config/qemu-rv64-max/rvmodel_macros.h` | Apache-2.0 and BSD-3-Clause; both upstream notices kept |
| `config/k3-x100/link.ld` | Upstream's `config/qemu-rv64-max/link.ld`, with `MEM_BASE` as the base address | Apache-2.0, upstream's repository license |
| `config/k3-x100/platform.mk` | New for the K3 | Apache-2.0 |
| `config/k3-x100/rvtest_config.h` | Generated by `make-rvtest-config.py` from upstream's `config/qemu-rv64-max/rvtest_config.h`, itself generated by riscv-unified-db | BSD-3-Clause-Clear, as its header states |
| `uart-ier-init.patch`, `build-portability.patch` | Changes to upstream's `common/` files | Apache-2.0 |
| `make-rvtest-config.py` | New tool | GPL-2.0-only |

The license texts are [Apache-2.0](../../LICENSES/Apache-2.0.txt) (upstream's
own `LICENSE`), [BSD-3-Clause](../../LICENSES/BSD-3-Clause.txt),
[BSD-3-Clause-Clear](../../LICENSES/BSD-3-Clause-Clear.txt) and
[GPL-2.0](../../LICENSE). Upstream has no `NOTICE` file.

The patch files carry no license header, so their bytes, and the SHA-256
values the build records for them, stay unchanged. `rvtest_config.h` must
stay identical to the generator's output, so it keeps the generator's
`Config: qemu-rv64-max` comment.
